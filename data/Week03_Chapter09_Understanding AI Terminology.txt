2. Two Main Approaches to AI
1. Rule-Based AI
Follows predefined instructions
Deterministic

Example:

If obstacle → turn left
2. Example-Based AI (Machine Learning)
Learns from data
Not explicitly programmed

Example:

Show many images → learn patterns
Key Insight

Most real systems:
 Combine BOTH approaches

3. Main AI Techniques (VERY IMPORTANT)
1. Supervised Learning
Uses labeled data
Input → known output

Examples:

Spam detection
Face recognition

 Most common (about 95% of applications)

2. Unsupervised Learning
Uses unlabeled data
Finds patterns

Examples:

Customer segmentation
Clustering
3. Reinforcement Learning
Learns through trial and error
Uses rewards and penalties

Examples:

Game AI
4. Deep Learning / Neural Networks
Multi-layer learning
Handles complex problems

Examples:

Image recognition
Voice assistants
5. Transfer Learning
Reuses knowledge from another model

 Saves time and data

6. GANs (Generative AI)
Generates new content
Two models compete

Examples:

Deepfakes
AI-generated images
7. Knowledge Graphs
Connects entities and relationships

Example:

Google search results panel
4. AI Metrics (VERY IMPORTANT FOR EXAMS)

AI is:
 NOT perfect
 Must be evaluated

Confusion Matrix

Four outcomes:

True Positive
True Negative
False Positive
False Negative
1. Accuracy
% correct predictions

 Problem:
Not always reliable

2. Precision
How many predicted positives are correct

 High precision = fewer wrong results

3. Recall
How many actual positives are found

 High recall = more coverage

🔥 Key Tradeoff

You cannot maximize both:

Precision ↑ → Recall ↓
Recall ↑ → Precision ↓

 Must choose based on context
